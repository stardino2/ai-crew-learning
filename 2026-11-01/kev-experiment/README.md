# Kev 분류 실험 및 멀티 모델 협업 보고

보고일: 2026-11-01 · 기본 평가 실행일: 2026-10-30

## 1. 목적

Kev-0.8B가 실제 메일 제목과 에이전트 라우팅 문제를 얼마나 잘 분류하는지 확인했다. 이후 분류 기준을 정비하고, 학습 데이터 수에 따른 성능 변화를 비교하기 위한 준비를 진행했다.

## 2. 진행 흐름과 역할

환경 조사 → 더미 메일 예비 실행 → 실제 메일 제목 100건 평가 → 합성 라우팅 100건 평가 → 독립 성능 분석 → 보고서 작성 → 학습량별 비교 실험 준비 순서로 진행했다.

| 담당 | 역할 |
|---|---|
| Codex | 초기 작업 분할, 진행 감시, 결과 검증, Argon에 관리 인계 |
| Gemini 3.8 Flash | 데이터 정리와 잠정 라벨 작성, 평가 실행, 학습 환경 및 실행 코드 준비 |
| GPT Luna | 합성 라우팅 문제 100건 작성 |
| Argon | 종합 보고와 성능 분석, 인계 이후 작업자 페인 생성·감시·종료 총괄 |
| GPT Sol low | 별도 성능 분석 및 평가 타당성 검토 |

## 3. Kev 실행 방식

공식 Python 서버와 PyTorch로 `jaredpalmer/kev-0.8b@v1.0`을 실행했다. 기반 모델은 `Qwen/Qwen3.5-0.8B-Base`이며, Ollama는 사용하지 않았다. 기본 평가는 로컬 CPU에서 수행했고, 평가 코드는 HTTP API `/v1/systemone`으로 입력과 선택지를 전달해 예측 및 확률을 저장했다. 평가 정답과 정답 근거는 모델 입력에서 제외했다.

## 4. 완료된 기본 평가 결과

| 항목 | 실제 메일 제목 분류 | 합성 라우팅 분류 |
|---|---:|---:|
| 평가 수 | 100건 | 100건 |
| 정상 응답 / 요청 오류 | 100 / 0 | 100 / 0 |
| 잠정 정답과 일치 | 34건 (34%) | 90건 (90%) |
| 다수 클래스 기준선 | 68% | 25% |
| HTTP 응답 시간 중앙값 | 0.524초 | 0.962초 |
| HTTP 응답 시간 95백분위 | 0.571초 | 1.041초 |

메일 분류는 요청·일정·공지·홍보·불명확의 5종으로 평가했다. 공지가 68건으로 편중됐고 일정은 없었다. 모델은 50건을 불명확으로 예측했으며, 전체 일치율은 다수 클래스 기준선보다 낮았다. 제목 중복을 제거하면 76종 중 21종이 일치했다.

라우팅은 도구 호출·추가 질문·직접 답변·거절을 각 25건씩 구성했다. 불일치 10건은 모두 도구 호출을 직접 답변으로 분류한 경우였으며, 도구 호출 재현율은 60%였다. 실제 도구를 실행한 실험은 아니다.

두 평가는 과업이 달라 합산하지 않았다. 정답은 사람 검수를 마친 확정 정답이 아니므로, 수치는 **잠정 라벨과의 일치율**이다. 특히 도구 호출 라우팅은 공식 모델 카드에서 지원 범위 밖으로 안내된 진단용 실험이다.

## 5. 해석과 한계

- 메일 분류에서는 분류 정책과 프롬프트의 정렬, 제목만으로 판단할 때의 정보 부족, 불명확 선택 쏠림을 우선 점검할 필요가 있다. 원인별 기여도는 통제 실험으로 확인하지 않았다.
- 메일 데이터에는 중복 제목과 분할 간 중복이 있어 독립 평가에 한계가 있다.
- 라우팅 문제는 합성 데이터이며 권한·상황 단서와 반복되는 의미 구조가 포함돼 있다. 90%를 일반적인 실사용 성능으로 해석할 수 없다.
- 모델 실행과 API 응답은 확인했다. 요청 오류가 없다는 사실이 분류 품질을 보장하지는 않는다.

## 6. 학습량별 비교 계획 및 준비 상태

총 5,000건을 학습 4,000건·검증 500건·최종 평가 500건으로 나누고, 추가 학습 없음·100건·500건·1,000건·4,000건을 비교할 계획이다. 분류 체계 후보를 먼저 검토한 뒤 대량 라벨링과 본 학습을 진행한다.

각 학습은 동일한 초기 Kev 체크포인트에서 독립적으로 시작한다. 작은 학습 집합이 큰 집합에 포함되도록 구성하고, 스레드와 유사 제목을 묶어 분할 간 유출을 줄인다. 고정 평가 집합에서 일치율·Macro-F1·클래스별 재현율과 학습 시간·자원 사용량을 함께 비교한다. Flash가 작성한 교사 라벨과 사람 검수 정답은 구분한다.

준비 산출물에는 분류 체계 후보안, 데이터 처리 설계, 학습량별 실행 코드, 격리 GPU 환경 및 합성 12건 학습 스모크 기록이 있다. **5,000건 본 데이터의 학습량별 성능 결과는 본 보고에 포함하지 않는다.** 소규모 GPU 스모크는 실행 가능성 확인이며, 실제 메일 분류 성능 개선을 증명하지 않는다.

## 7. 공개 범위

본 문서는 보고용 요약이다. 실제 메일 제목·본문·주소·메시지 ID, 원본 데이터, 인증 정보, 작업자 로그, 모델 체크포인트는 포함하지 않았다. 기존 상세 HTML에는 실제 메일 기반 제목이 내장되어 있어 이 공개 요약에 첨부하지 않았다.
