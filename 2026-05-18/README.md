# 05/20 Harness Engineering Talk Kit

This workspace contains the materials for a 10-minute Korean introduction and demo of Harness Engineering for FE/BE developers and system engineers.

## Contents

- `slides/` - Slidev deck with speaker notes and source slide.
- `mini-status-harness/` - Small status-page demo project with a built-in harness.
- `demo-video/` - Archived HyperFrames source for the earlier video version.

## Intended Flow

1. Present the Slidev deck.
2. Use the HTML demo slides during the mini-status-harness section.
3. Open the generated evidence report if a live browser handoff is useful.
