# Archived Demo Video

This directory contains the earlier HyperFrames composition for the 2-3 minute demo video. The current talk uses HTML slides instead of a separate rendered video.

Recommended final duration: 150 seconds.

## Render

If HyperFrames and its browser dependencies are available:

```powershell
npx hyperframes lint
npx hyperframes inspect
npx hyperframes render --output renders/mini-status-harness-demo.mp4 --quality standard
```

## Current Usage

Keep this directory as an archive only. Use `slides/standalone.html` or the Slidev deck for the live talk flow.
