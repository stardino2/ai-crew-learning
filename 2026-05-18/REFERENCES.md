# References

Use these as the source slide and Q&A backup. Avoid claiming that "Harness Engineering" is a fully settled industry term.

## Strongly Supported Claims

- Automated tests, fast feedback, and deployment automation are established DevOps/SRE/CI/CD directions.
- AI coding agents increase the need to put generated work into observable, testable, policy-bound workflows.
- Human reviewers should focus on standards, exceptions, and accountability rather than repeatedly checking the same mechanical conditions.

## Recommended Wording

> Harness Engineering은 AI가 만든 결과를 사람이 매번 손으로 검증하는 대신, 팀의 자동 검증 기준을 통과하게 만드는 일입니다. 하네스는 AI 결과가 팀의 빌드·테스트·리뷰·운영 기준을 지나가게 하는 실행 환경입니다.

## Avoid

> 업계는 Harness Engineering이라는 용어로 이미 합의했습니다.

> 용어는 아직 정착 중이지만, OpenAI/Anthropic/GitHub/DORA 자료가 가리키는 방향은 비슷합니다.
