# AGENTS.md

## 슬라이드 작업 규칙

`slides/` 디렉토리의 파일(`slides.md`, `style.css`, `standalone.html` 등)을 만들거나 수정할 때는 **반드시 먼저 프로젝트 루트의 `design.md`를 읽어라.**

`design.md`는 이 발표 자료 전체의 디자인 시스템(컬러, 타이포그래피, 컴포넌트, 간격, do/don't)을 정의한다. Apple 디자인 언어를 기반으로 한 토큰 시스템이며, 슬라이드의 모든 시각적 선택(색, 폰트 크기/굵기, 라운드, 그림자, 여백 등)은 이 문서의 토큰을 따라야 한다.

### 적용 방식

- 슬라이드 관련 작업을 받으면 **첫 행동으로** `design.md`를 Read한다. 이미 같은 세션에서 읽었더라도, 작업이 디자인 결정을 포함하면 다시 확인한다.
- 컬러는 hex를 인라인하지 말고 `design.md`에 정의된 의미(`{colors.primary}`, `{colors.canvas-parchment}` 등)에 해당하는 값을 사용한다.
- 타이포그래피, 라운드, 그림자, 간격은 `design.md`의 토큰 표(`{typography.*}`, `{rounded.*}`, `{spacing.*}`)에서 골라 적용한다.
- `design.md`의 "Don't" 섹션을 위반하지 않는다 — 특히: 두 번째 액센트 컬러 도입 금지, 카드/버튼/텍스트에 그림자 금지, 데코레이션용 그래디언트 금지, body 굵기 500 금지.

### 예외

- 단순 오타 수정, speaker note(`<!-- ... -->`) 변경, 슬라이드 텍스트 카피만 바뀌는 작업처럼 시각적 결정이 없으면 `design.md` 재확인은 생략 가능하다.
