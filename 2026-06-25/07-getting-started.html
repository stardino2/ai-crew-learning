⚙ 시작하기 — 앱 설치·구동

처음 까는 분을 위한 실전 시작 가이드입니다. 설치 → 로그인 → 첫 세션까지만 다룹니다. 개념·고급 기능은 ③ 도구사용법에 있습니다.

⏱ 순서: 여기서 설치·로그인 → ① 빠른시작으로. 설치만 되면 ①의 토큰 규칙·템플릿을 바로 쓸 수 있습니다.
⚠ 사내 배포 방식이 우선입니다. 설치 명령·로그인(SSO)·허용 도구는 회사 설정에 따라 다를 수 있습니다. 아래는 일반 공개 절차이며, 사내 안내가 있으면 그쪽을 따르세요. 첫 로그인 전 ⚠ 안전수칙 먼저 확인.

AClaude Code (CLI) — 가이드 핵심 도구

터미널에서 도는 에이전트형 코딩 도구입니다. 멀티파일·코드베이스 탐색·도구 연동에 강합니다.

1. 설치

# Node.js 18+ 필요. 전역 설치:
npm install -g @anthropic-ai/claude-code

# 확인:
claude --version
사내 배포를 쓰는 경우
회사가 사내 레지스트리·래퍼 스크립트·프록시를 제공하면 그 절차를 따르세요. 버전·인증이 공개판과 다를 수 있습니다.

2. 로그인

# 프로젝트 폴더에서 실행하면 첫 구동 시 로그인 안내:
claude

브라우저 인증(OAuth) 또는 사내 SSO/API 키로 로그인합니다. 엔터프라이즈는 보통 조직 계정으로 연결됩니다.

3. 첫 세션

  • 작업할 프로젝트 폴더에서 claude 실행. 대화창이 열립니다.
  • 요청은 자연어로: "이 레포 구조 요약해줘", "login() 버그 원인부터 짚어줘".
  • 파일은 통째 붙이지 말고 @경로/파일로 참조 (토큰 절약 → ①).
  • 파괴적·prod 작업은 승인창이 뜹니다. 검토 후 수동 승인 (자동 차단).

4. 필수 명령

명령용도
/clear작업 끝나면 대화 비우기 (토큰 절약)
/help사용 가능한 명령 목록
/review코드 리뷰 등 내장 스킬 호출
@파일파일 콕 집어 참조

계단식 사용법(플랜 모드·서브에이전트·스킬)은 ③ Claude 7계단.

5. CLAUDE.md 만들기 (선택, 권장)

프로젝트 루트에 CLAUDE.md 텍스트 파일을 두면 매 세션 자동으로 읽힙니다. 프로젝트 규칙·자주 쓰는 명령을 적어두면 같은 설명을 반복하지 않아 토큰이 절약됩니다.

# 예: ./CLAUDE.md
- 테스트: npm test
- 빌드: npm run build
- 코드 스타일: 기존 컴포넌트 패턴 따를 것
- prod 배포 명령은 생성만, 실행은 사람이

BCodex (CLI)

에디터 통합과 CLI 에이전트 둘 다 되는 도구입니다. 빠른 반복·명확한 범위 작업에 민첩합니다.

1. 설치

# Node.js 18+ 필요. 전역 설치:
npm install -g @openai/codex

# 확인:
codex --version
대안 설치
패키지 매니저(brew 등)나 사내 배포를 제공하면 그 절차를 따르세요. 공개판과 인증·버전이 다를 수 있습니다.

2. 로그인

# 프로젝트 폴더에서 실행 → 첫 구동 시 로그인 안내:
codex

ChatGPT 계정 또는 API 키로 인증합니다. 엔터프라이즈는 조직 계정/SSO로 연결되는 경우가 많습니다.

3. 첫 실행 · 승인 모드

  • 프로젝트 폴더에서 codex 실행 후 자연어로 요청.
  • 승인 모드를 이해하세요: 제안만 / 편집 자동적용 / 더 넓은 자동화 단계가 있습니다. 사내는 자동 적용이 차단이라 수동 검토가 기본입니다.
  • 범위를 좁혀 주면("이 함수만, 이 입력→이 출력") 가장 빠르고 정확합니다.
⚠ 자동 적용·자동 승인은 사내 정책으로 막혀 있습니다. 우회하지 마세요(→ 안전).

C데스크톱 앱 (보조)

Claude / ChatGPT 데스크톱 앱은 코딩 에이전트가 아니라 대화·문서·이미지 분석 용도의 보조 도구입니다. 코드 작업은 위 CLI를, 빠른 질문·스크린샷 분석은 데스크톱 앱을 쓰면 편합니다.

설치·로그인

  • 공식 사이트(또는 사내 배포)에서 설치 파일을 받아 설치합니다.
  • 조직 계정/SSO로 로그인합니다. 개인 계정에 업무 데이터 입력 금지(→ 안전).

잘 맞는 작업

  • 에러 화면·다이어그램 스크린샷 붙여 분석.
  • 긴 스펙·로그 요약 (대용량은 Gemini 활용 → ②).
  • 코드 자동 수정·실행이 필요하면 데스크톱 말고 CLI로.
💡 화면·메뉴는 버전마다 바뀝니다. 이 문서는 설치·구동 흐름만 다룹니다. 세부 UI가 다르면 각 앱의 /help·도움말을 보거나 사내 안내를 확인하세요.
