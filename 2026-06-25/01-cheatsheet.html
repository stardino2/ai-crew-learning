① 빠른시작 치트시트

전원 필수입니다. 이 문서 하나로 일상 작업 80%가 커버됩니다. 안전수칙은 ⚠ 안전에서 별도로 확인하세요.

A토큰 절약 6규칙 — 토큰 부족 = 비용. 1순위

각 규칙의 예시를 누르면 펼쳐집니다.

  • DO한 세션 = 한 작업. 끝나면 /clear. 대화가 길수록 과거 전체를 매번 재전송 → 토큰 폭증.
    예시
    버그 수정 끝 → /clear → 다음 기능 시작. 안 끊으면 이전 대화 전체가 매 질문마다 다시 전송됩니다.
  • NO파일 통째로 붙이지 마라. "이 파일 전체" 대신 "login() 함수만" 범위 좁히기.
    예시
    ❌ "이 파일 전체 봐줘" (1500줄)
    ✅ "login() 함수만" (40줄)
  • DO탐색은 위임. "이 기능 어디서 처리돼?"는 탐색 서브에이전트에 → 결론만 회수. 파일 덤프 안 들임.
    예시
    ❌ 관련 파일 5개 다 붙여넣고 질문
    ✅ "결제 로직 어디서 처리돼?" 위임 → 위치(file:line)만 회수
    호출: 그냥 자연어로 "탐색은 서브에이전트한테 맡겨 결론만 줘"라고 하면 됩니다. 자세히는 ③ 도구사용법.
  • DO모델 등급 분리. 오타·포맷은 싸고 빠른 모델, 설계·멀티파일 리팩터만 비싼 모델.
    예시
    오타 수정·코드 정렬 → 싸고 빠른 모델
    아키텍처 변경·멀티파일 리팩터 → 비싼 모델
  • TIP캐시 5분 룰. 작업을 끊지 말고 연속으로. 오래 비웠다 재개하면 캐시 미스 = 재과금.
    예시
    연속 작업 = 캐시 적중(저렴). 5분 안에 재개하면 여전히 적중합니다.
    오래 비웠다 재개 = 캐시 만료 → 컨텍스트를 정상가로 다시 처리(추가 벌금이 아니라 할인이 사라지는 것). 그래도 손해라 끊지 않는 게 이득.
  • NO같은 파일 반복 읽기 금지. 방금 보거나 고친 파일을 "확인차" 다시 읽지 마라.
    예시
    방금 고친 파일을 "잘 됐나" 다시 읽으면 같은 토큰을 두 번 씁니다. 도구가 이미 결과를 알고 있습니다.
체감해 보세요. 1500줄 파일을 매 질문에 첨부 × 10회 = 15,000줄을 10번 재전송하는 셈입니다. 필요한 40줄만 + /clear 하면 같은 작업을 토큰 1/10로 끝냅니다.
