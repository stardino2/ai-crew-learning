③ 도구 사용법

기본기에서 고급으로 가는 계단식 구성입니다. 처음엔 1~3계단만 익히세요. 규칙 박제는 📄 AGENTS.md, 워크플로우 묶음은 🧩 플러그인에 있습니다.

AClaude 7계단

위에서부터 보세요. 1~3계단이 90%의 효과를 냅니다. 익은 뒤 아래로 내려가면 됩니다.

  1. 컨텍스트 제어 — /clear로 작업 단위 끊기 + CLAUDE.md에 규칙 박제. 토큰 직결 (메커닉 자세히 → ①, 규칙 박제 → 📄 AGENTS.md)
  2. 파일 참조 — @경로/파일로 콕 집기(통째 붙여넣기 대신). (자세히 → ①)
  3. 플랜 모드 — 큰 작업은 코드 짜기 전에 계획부터 받기. 폭주·헛수정 방지.
  4. 효율적 승인 — 매 작업 승인창 뜸(자동 차단). 자주 쓰는 읽기 전용 명령은 allowlist 등록해 반복 승인 줄이고, 위험 명령은 즉시 거부. 자동승인은 사내 차단 — 기대 말 것
  5. 서브에이전트 — "이거 어디서 처리돼?" 같은 탐색을 위임 → 결론만 회수, 메인 컨텍스트 안 더럽힘. 호출법: 그냥 자연어로 "탐색은 서브에이전트한테 맡겨 결론만 줘"라고 하면 도구가 별도 에이전트로 격리 실행합니다. 자주 쓰면 .claude/agents/에 커스텀 에이전트(이름·역할·쓸 도구)를 정의해 "○○ 에이전트로 해줘"로 지정 호출할 수도 있습니다.
  6. 슬래시 커맨드 · MCP — 내장 명령(/review 등)과 외부 연동(MCP)으로 워크플로우 확장.
  7. 스킬 — 반복 작업을 재사용 패키지로. 쓰는 법은 아래 B, 더 많은 묶음은 🧩 플러그인.

B스킬 — 쓰는 법

스킬 = "이 작업은 이렇게 해" 묶음 지침. 설치돼 있으면 상황에 맞을 때 자동 제안되거나 /스킬이름 으로 호출.

  • 설치된 스킬 목록 확인 → 내 작업에 맞는 게 있나 먼저 본다.
  • 호출은 슬래시. 예: 코드리뷰 스킬 있으면 /code-review.
  • 없는 걸 지어내지 마라. 목록에 있는 것만 호출.

CCodex 핵심 3

두 가지 표면

에디터 통합(인라인 제안 수락/수정)과 CLI 에이전트(멀티파일·코드베이스 탐색) 둘 다 됩니다. 작업에 맞는 표면을 고르세요.

명확한 범위가 강점

"이 함수만, 이 입력→이 출력"처럼 명확할수록 빠르고 정확합니다. 멀티파일도 되지만 진가는 빠른 반복입니다.

승인 모드

변경 적용 전 확인합니다. 자동 적용은 사내 차단이라 수동 검토가 기본입니다.

E컨텍스트 관리 심화

  • 요약-후-계속. 대화가 길어지면 "지금까지 상태를 10줄 요약" → /clear → 요약 붙여 재개. 긴 작업에서 토큰 폭증을 끊는 핵심 기법입니다.
  • 나머지 기본기는 ①로. 메모리 파일 빼두기·경로 참조·서브에이전트 격리는 토큰 절약 6규칙에 정리돼 있습니다 → ① 빠른시작. 규칙을 영구 박제하려면 📄 AGENTS.md.
